# 问题一：四方案评选与封版协议

## 目的

在问题一阶段测试四套完整方案，选择唯一优胜方案。评选完成后封版质量指标体系、领域映射、配比表示、模型形式和评价口径，后续问题不得根据结论反向修改这些定义。

## 数据边界

- A4/A5：训练、重复交叉验证和超参数选择。
- A6/A7：模型确定后的独立验证，不反复用于调参。
- A8-A11：60M、1B 的跨规模迁移检验，不与 1M 的绝对误差直接混合。
- A12-A15：估计或外推数据，只报告稳健性，不用于证明预测准确。

## 统一实验条件

1. 四套方案使用相同样本、相同折、相同随机种子。
2. 13 个验证领域分别计算指标，禁止只报告未经标准化的简单平均 Loss。
3. 所有预处理步骤必须在每个训练折内部拟合，防止数据泄漏。
4. 超参数搜索空间和停止条件在运行前登记在配置文件中。
5. 每次正式运行保存配置、代码提交号、环境、随机种子和逐折结果。
6. 原始配比保留三位小数，行和存在至多约 0.004 的舍入偏差；读取后统一按行重新归一化为 1。

## 质量 Q 的有效性检查

由于数据没有真实质量标签，Q 不以训练拟合优度作为唯一依据。每套方案报告：

- Bootstrap 后文档或领域排序的 Spearman 稳定性；
- 删除单个指标、改变异常值阈值后的敏感性；
- A1 与 A2/A3 扩展数据上的领域结论一致性；
- 高分、低分和指标冲突文本的盲审合理性；
- 在训练集内部加入 Q 后，对留出 Loss 预测是否产生稳定增益。

## Loss 预测指标

- 主指标：13 个任务的平均标准化 RMSE，越小越好；标准差使用训练折估计。
- 次指标：标准化 MAE、各任务 R²、平均 Spearman 相关系数。
- 优化指标：Top-k regret，衡量模型推荐配比距离真实最优值的差距。
- 风险指标：最差任务误差、逐折波动和参数/特征选择稳定性。

## 唯一冠军选择规则

1. 找到交叉验证平均标准化 RMSE 最小的方案。
2. 应用一倍标准误差规则，将与最优方案差异不足一个标准误差的方案纳入候选集。
3. 候选集中依次比较：Top-k regret 更小、Spearman 更高、Q 的 Bootstrap 稳定性更高、模型复杂度更低。
4. 得到唯一冠军后，仅使用 A6/A7 做一次独立验证。
5. 若独立验证出现显著失效，必须记录失败并重新检查数据或实验协议，不能直接根据测试集改选模型。

## 问题一封版内容

- 指标正负方向、变换、缺失值和异常值规则；
- Q 的维度、权重或载荷、聚合公式及不确定性计算；
- 质量数据到训练领域的映射；
- 配比的数学表示和零值处理；
- p 到 13 个 Loss 的模型形式和超参数；
- 随机种子、数据切分和全部评价指标。

第二问可以在以上固定定义上增加 N、D、C 等变量并估计新参数，但不得为了改善后续结论而重定义 Q 或 p。
